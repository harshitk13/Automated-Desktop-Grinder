# Automated Desktop Grinder (Design Patent)
**Project Timeline:** January 2023 – May 2023

### Overview
This repository contains the design patent document and mechanical CAD assemblies for a novel automated precision desktop grinding machine. 

### Key Features
* Developed complete CAD assemblies in Fusion 360 / SolidWorks.
* Integrated Arduino-based embedded control with automated actuation and safety interlocks.
* **Awarded a Design Patent** for novel mechanical configuration and system architecture.
